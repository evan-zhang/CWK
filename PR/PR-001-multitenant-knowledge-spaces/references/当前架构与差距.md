# 当前架构与多租户目标差距

> 审计日期：2026-08-19
> 审计方式：只读检查当前分支 `rt/RT-002-interactive-action-center`，基线提交 `8720906`。

## 1. 可作为改造基线的现有能力

- 按 `report_id` 归档、SHA-256 校验、版本晋级和 manifest。
- 回复/审批不可变时间线及哈希去重。
- 统一事实摘要结构和逐字引文校验。
- 实体目录、别名、实体族、实体硬范围和安全拒答。
- Wiki 索引、raw 回读、完整性审计和 fail-closed 查询。
- DocDB 有界重试、自愈和同步状态。
- RT-008 的用户—汇报关系能力，可作为访问图的输入。

## 2. 当前单租户假设

### G-01：配置和密钥是单实例

- `.env.example` 只描述一份 `CWORK_APP_KEY`。
- `install.sh` 生成一份 `.env` 和 `cwk-mirror.local.json`。
- `docs/INTERNAL_DISTRIBUTION.md` 明确按“一位用户一份实例”操作。

### G-02：运行状态是仓库级共享

- nightly 默认使用仓库级 `runs/`、`state/collection-state.json` 和单一 mirror。
- 采集状态以 `report_id` 为键，同时保存 `readStatus`、`todoStatus`、`hasNewReply` 等用户视角状态，没有 `tenant_id` 维度。
- DocDB retry queue 和同步状态也是仓库级文件。

### G-03：raw 混合共享事实与个人视角

`scripts/cwk_collect_live.py` 生成的 Markdown 同时包含：

- 标题、正文、作者、时间等待验证的共享候选字段；
- source lane、读取/待办状态等用户视角字段；
- 回复、审批节点和允许操作等可能受权限影响的字段。

因此现有 raw 不能原样移动到公司级共享对象层。

### G-04：查询入口缺少租户强制绑定

- 查询器可接收任意 mirror 路径。
- 当前没有可信 `agent_id → tenant_id` 的宿主机绑定。
- 没有在候选召回和 raw 回读两处都执行 ACL 的双重门禁。
- 共享目录一旦挂入沙箱，路径知识可能导致越权。

### G-05：知识治理是全局配置

- 实体族注册表以仓库级 `config/entity-family-registry.json` 为主。
- 目前没有租户 profile、专题空间、路由器和用户确认日志。
- 手工修改生成 Wiki 会被重建覆盖。

### G-06：调度和故障域未租户化

- 采集锁、状态、日志、重试和运行输出未按租户隔离。
- 一个租户失败可能污染或阻塞全局任务。
- 还没有错峰、配额、租户级熔断和成本统计。

### G-07：现有 sandbox 不是用户租户沙箱

当前 AI reviewer 的 sandbox/zero-tool 配置用于内容处理隔离，不能替代普通用户 Agent 的数据隔离和身份授权。

## 3. 必须建立的新边界

```text
Gateway identity plane
  agent_id -> tenant_id (不可由用户覆盖)
          |
Tenant runtime plane
  config/state/runs/locks/retries/logs/secrets reference
          |
Access control plane
  (tenant_id, report_id, permissions, validity)
          |
Shared evidence plane
  immutable object + report version catalog
          |
Tenant knowledge plane
  profile + routes + spaces + indexes + cache
```

## 4. 关键迁移原则

1. 先建立新数据契约和安全门禁，再迁移现有 raw。
2. 使用双读/影子写和逐对象 crosswalk 核验，不一次性替换当前唯一权威 raw。
3. 现有单用户实例作为首个 tenant 导入，迁移前后 report 数量、版本链、正文/时间/来源语义必须一致；分别保存 `legacy_source_sha256` 与 `canonical_sha256`，通过确定性 crosswalk 证明转换关系，不要求两种序列化哈希相等。
4. 未完成双身份差异验证前，评论、审批节点和附件元数据全部进入 tenant overlay；临时下载/预览 URL 永远不得进入 canonical。只有经版本化 `verified_shared_extensions` 清单独立批准的字段才可提升为共享字段。
5. 未完成权限撤销、备份恢复和跨租户渗透测试前，不开放真实多用户生产。
