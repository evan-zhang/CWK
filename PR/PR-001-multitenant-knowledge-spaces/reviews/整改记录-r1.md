## 2. Major 决策项整改（M1–M3）

### M1 — Query Broker transport + 可信 Agent 身份
- 位置：`PRD.md` §7 FR-17；`DESIGN.md` §5 C-13。
- 决议：首期强制 **OpenClaw 受控 Tool** 主 transport；**UDS + SO_PEERCRED** 后备本机实现；loopback HTTP + 自报 `agent_id` 明确禁止。
- G1 硬门禁：`plans/开发计划.md` §3 RT-011B 与 §12 门禁对照表；ADR/`security_defaults.json` 由 RT-011B 落地。
- 讨论闭合：`references/讨论决策记录.md` §6 项 6 已划线并注明收敛结果。

### M2 — Legacy raw 分解器、fail closed、迁移对账
- 位置：`DESIGN.md` §13 Phase M2/M3。
- 新增：
  - `LegacyRawDecomposer` 契约、无法反解走 `review/legacy-undecomposable/` fail closed；
  - `MigrationReconciler` 五分类 + 对账报告作为 M3 通过门禁；
- 计划：`plans/开发计划.md` §5 RT-013 覆盖 `cwk_legacy_decomposer.py`、`cwk_migration_reconciler.py`。

### M3 — 100–200 篇 Proposal 分批/聚合/零工具/prompt injection/manifest+SHA
- 位置：`DESIGN.md` §7.2。
- 新增：
  - 分批 chunk 20–30 篇 + 确定性 reducer 聚合；单 chunk 失败上限后整体 `proposal_error`；跳过判定不由 AI 决定；
  - 零工具 sandbox（无网络/无 FS/无 sub-agent）；prompt 明确 raw 为不可信；
  - JSON schema + 证据/ACL + 禁止字段扫描；
  - `sample_manifest_v1`（不可变 + SHA）；`profile_sha256 = sha256(canonical_json(proposal) + sample_manifest_sha256 + prompt_template_sha256 + model_id)`；缺一拒绝激活。
- 计划：`plans/开发计划.md` §7 RT-015 全流程。
