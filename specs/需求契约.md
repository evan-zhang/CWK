# CWK RT-001 需求契约

## 1. 业务目标

在现有只读规则 pipeline 之上增加 AI 理解、跨篇归并、管理版简报和质量复核能力，提升日报去重、事件锚点、行动项和风险识别质量，同时保留规则版作为稳定基线。

## 2. 用户角色

- 运行者：配置工作协同 appKey、模型和 nightly 参数的同事。
- 阅读者：阅读每日规则版与 AI 增强版简报的管理者。
- 审核者：对比规则版、AI 增强版和质量报告，决定是否扩大试运行。

## 3. 使用场景

- nightly 只读采集后，对每篇汇报生成可追溯的结构化理解。
- 将同批和历史延续事项归并为管理事件，减少重复信息。
- 生成 AI 增强版 Markdown/HTML，同时保留规则版。
- 对两版简报进行质量复核并记录改进、退化和证据风险。

## 4. 功能范围

### 必须实现

- 单篇理解、跨篇归并、增强 digest、质量复核四个 stage。
- AI 开关、dry-run、模型、并发和超时配置。
- AI 失败降级，不阻断规则 pipeline。
- manifest 记录 AI 状态、模型、耗时和输出，不记录秘密或 prompt。
- CI 同时验证 AI 关闭和 AI dry-run 两条路径。

### 明确不做

- 不修改 CWork 状态，不回复、审批、标已读或完成待办。
- 不把 AI 增强版直接替换为生产唯一版本。
- 不提交真实 raw、run、prompt 或 AI 输出。
- 不修改生产 cron 开关。
- 不做前端 UI 和公司级 GA 发布。

## 5. 输入

- `runs/<run_name>/raw/*.md`
- `runs/<run_name>/extracted/*.json`
- `runs/<run_name>/digest-human-v4.md`
- 可选历史运行名和模型配置。

## 6. 输出

- `ai-understanding/*.json`
- `ai-record-summary.json`
- `ai-events.json`
- `ai-daily-priorities.json`
- `digest-ai-enhanced.md/html`
- `quality-review.json/md`
- 含 `ai` 与 `degraded` 字段的 nightly manifest。

## 7. 业务规则

- 每条 AI 结论必须关联 `report_id`；关键行动、风险和决策应带原文证据。
- AI 关闭时，现有规则 pipeline 行为保持不变。
- AI 失败时保留规则版并继续发布，manifest 标记降级。
- dry-run 必须完全离线、确定性、无需模型密钥。
- 默认使用 OpenClaw Agent runner；供应商和凭证不得硬编码。真实调用只允许无 Skills、工具面为 `minimal + read`、Agent 级只读 sandbox、workspace 固定为项目内 `.cwk-ai-runtime` 的专用 Agent。

## 8. 异常情况

- 单篇模型失败：以规则抽取生成 fallback JSON，标记 `ai_status=failed`。
- 聚类失败：跳过增强 digest 和质量复核，规则版继续。
- 质量复核失败：增强 digest 保留，manifest 标记降级。
- AI 输出不是合法 JSON 或缺证据：视为该 stage 失败或 fallback。

## 9. 权限与安全要求

- AI stage 仅可读取本地 run 产物。
- 不把 appKey、token、环境变量值、完整 prompt 写入 manifest 或日志。
- 调用 OpenClaw Agent 时不启用消息投递。
- GitHub 继续忽略 `runs/`、`knowledge/`、`.env` 和本地配置。

## 10. 验收标准

- `CWK_AI_ENABLED=false make test` 通过。
- `CWK_AI_ENABLED=true CWK_AI_DRY_RUN=true make test` 通过。
- dry-run 生成 RT 约定的全部 AI 产物。
- 每个 priority 和 event 都能追溯到输入 `report_id`。
- manifest 不包含 appKey、token 或 prompt 正文。
- 模拟 AI 失败时规则版仍成功，且 `degraded=true`。
- 生产 cron 未被本次交付修改。

## 11. 测试场景

- 正常：smoke fixture + AI dry-run，完整生成两版 digest 和质量报告。
- 兼容：AI 关闭，原 smoke 输出和规则版 manifest 保持有效。
- 异常：模型 runner 不可用，规则版成功且 AI 降级。
- 安全：扫描 manifest 和 git diff，不出现秘密值、真实 raw 或 prompt。
