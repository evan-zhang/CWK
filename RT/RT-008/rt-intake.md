# RT-008：后台权威汇报关系接口

## 背景

CWK 曾依据汇报人字段、节点人员列表和收发件/待办 scope 在本地推断“本人是汇报人、建议人、审批人、接收人或仅权限可见”。该做法重复实现工作协同后台业务规则，无法可靠覆盖委托、转办、动态节点、多人多角色、节点撤销和未来新增角色。

## 目标

由工作协同后台按当前 AppKey 对应用户，权威返回该用户与一批汇报的关系、当前待处理动作和判定状态。CWK 只消费并展示该结果，不再遍历人员清单自行得出负面关系结论。

## 边界

- 本 RT 交付接口契约、CWK 客户端适配、安全降级和页面验证。
- 工作协同后台接口的开发、部署和开放 API 发布需由后台团队完成，不在 CWK 仓库权限范围内。
- 后台接口未部署、超时或单条无法判定时，CWK 显示“关系待确认”，不得显示“与我无关”。
