# 需求契约

## 用户、动作与系统响应

| 用户/系统动作 | 系统响应 | 成功标准 | 失败处理 |
| --- | --- | --- | --- |
| CWK 查询一批汇报关系 | 后台以 AppKey 当前用户为主体批量判定 | 每个 reportId 返回独立判定 | 单条失败不影响其他条目 |
| 后台判定用户与汇报相关 | 返回全部角色、主角色、是否待处理及允许动作 | CWK 不再二次推断角色 | 不认识的新角色按 participant 展示 |
| 后台判定仅权限可见 | 明确返回 `visibility=visible_only` | CWK 才可显示“仅权限可见” | 缺少明确结论不得做负面判断 |
| 接口不可用或数据不足 | 返回/降级为 `status=unknown` | 页面显示“关系待确认” | 不影响原文收录与 nightly 主流程 |

## 后台接口契约

### 请求

`POST /open-api/work-report/report/relation/batchQueryCurrentUser`

- 身份：仅从请求头 `appKey` 解析当前用户，不接受客户端传入 employeeId 代替身份。
- 请求体：

```json
{
  "reportIds": ["2080000000000000001", "2080000000000000002"]
}
```

- 单批建议上限：200 个 reportId；重复 ID 由后台去重。

### 响应

```json
{
  "resultCode": 1,
  "data": {
    "relationVersion": "work-report-relation.v1",
    "evaluatedAt": "2026-08-12T12:00:00+08:00",
    "items": [
      {
        "reportId": "2080000000000000001",
        "status": "resolved",
        "visibility": "related",
        "primaryRole": "advisor",
        "roles": ["recipient", "advisor"],
        "actionRequired": true,
        "pendingActions": ["submit_advice"],
        "reasonCode": "ACTIVE_SUGGEST_NODE"
      },
      {
        "reportId": "2080000000000000002",
        "status": "resolved",
        "visibility": "visible_only",
        "primaryRole": "observer",
        "roles": [],
        "actionRequired": false,
        "pendingActions": [],
        "reasonCode": "PERMISSION_ONLY"
      }
    ]
  }
}
```

### 字段约束

- `status`: `resolved | unknown | not_found | forbidden`。
- `visibility`: `related | visible_only | unknown`。
- `roles`: 后台返回全部角色；允许未来扩展，客户端不得因未知值失败。
- `primaryRole`: 后台按业务优先级确定；CWK 不重排节点推断主角色。
- `actionRequired`: 后台对当前时点的权威待处理结论。
- `pendingActions`: 后台给出的当前可办理动作代码；CWK 仅生成 Shadow Mode 预览。
- `reasonCode`: 稳定机器码，不返回或暴露不必要的全量人员名单。
- 每个请求 ID 必须恰好返回一个 item；无法判定返回 `unknown`，不能静默遗漏。

## 验收标准

1. 后台返回 `visible_only` 时，页面显示“仅权限可见”，不计入必须处理。
2. 后台返回多个角色时，页面使用 `primaryRole`，同时保留 `roles` 供审计。
3. 后台接口缺失、超时、漏回单条或返回未知字段时，页面显示“关系待确认”，不自行遍历 nodeList 推断。
4. 收件箱/待办 scope 仍可用于选材，但不得替代后台关系分类。
5. 接口故障不影响 raw、时间线、Wiki 和每日页面生成。
