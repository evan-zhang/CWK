## 9. 2026-08-12 本人关系标记补充交付

### 已完成内容

- 新增统一本人关系判定模块，员工 ID 优先匹配汇报人和所有流程节点人员。
- `inbox/unread/pending` 不再自动等同于本人是收件人；只有明确人员证据或本人待办/发件范围才认定相关。
- 节点数据完整且本人不在相关人员清单时，行动中心显示 `仅权限可见 · 与我无关`，卡片弱化并移除审批、建议和发表意见类操作。
- 每日简报同步显示整组或部分“仅权限可见”数量。
- nightly 已显式配置当前账号员工 ID 与姓名，后续每晚自动执行同一判定。

| DocDB 发布 | 通过 | 4 个既有页面对象均走 `update_version`，failed=0 |
| 云端回读 | 通过 | 行动中心全文回读成功，特殊标记出现 40 次 |

### 测试与验证

- 全量 unittest：125/125。
- Wiki smoke：14/14。
- Python 语法检查与 `git diff --check`：通过。
- 页面脚本继续通过 Node 语法检查；本次只增加关系标记和样式，未改变已验证的页签/按钮事件链。

### 风险与边界

- 负向判定要求节点详情完整；接口失败或身份未配置时只标 `unknown`，不会武断显示“与我无关”。

- 标记仅用于个人阅读与注意力排序，不改变 CWork 权限、已读状态或流程节点。
