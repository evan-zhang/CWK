## 阶段 B：Decomposer & Importer 主模块

- [x] B-01：`scripts/cwk_legacy_raw_import.py`
  - LegacyImportError / LogInjectionDetected / LegacyDriftDetected 错误
    分类；`__str__` 不含绝对路径或凭据。
  - `LegacyRawDecomposer`：frontmatter/JSON 段解析、正文抽取、
    3 元组构造、`decompose_report` 输出；一律 fail-closed，无
    truncation / 猜测。
  - `LegacySource`：`O_DIRECTORY | O_NOFOLLOW` 全程；symlink /
    hardlink / oversize / bad grammar 跳过；`snapshot` / `verify_no_drift`
    / `iter_files_with_hashes`。
  - `ShadowImporter`：initialize（创建 `registry/rt016-crosswalk/`），
    `import_one`（publish → observe → optional promote+upsert →
    crosswalk CAS → manifest append），`import_batch`（带 pre/post
    zero-drift），`read_crosswalk / iter_crosswalks / iter_reviews
    / iter_manifest`，`recover`（`.cwk-tmp-*` sweep）。
  - macOS `AccessLedger.observe` ENOENT 竞态：8 次 exponential
    jitter 重试，其他错误直接抛 `LegacyImportError(code=ledger_denied)`。
  - 全 Public API 通过 `__all__` 白名单暴露。
- [x] B-02：`scripts/cwk_migration_reconciler.py`
  - `MigrationReconciler.reconcile`：`verify_no_drift` → 递归 hash
    legacy tree → 枚举 RT-016 crosswalk / review → 对每条 crosswalk
    调 RT-014 `read_version` 校验 → 分类 both_equal / only_legacy /
    only_new / new_undecomposable → 输出严格 schema 校验过的
    `ReconciliationReport`。
  - `zero_drift_verified=False` 不阻断报告，但暴露给上层 gate。
