## 3. 验证细节

### 3.1 稳定性抽样

- `python3.11 -m unittest discover -s tests -p 'test_rt016_*.py'`
  连续 30 次运行：30 次 `OK`。
- `python3.11 -m unittest tests.test_rt016_attacks.ConcurrentImportTests`
  连续 30 次运行：30 次 `OK`。

关于并发：`ShadowImporter.import_one` 在 macOS 上包裹 RT-015
`AccessLedger.observe` 的 `FileNotFoundError` 竞态（RT-014 已在
`cwk_shared_evidence._flock_with_retry` 中文档化的相同现象）；重
试上限 16 次 + 50 ms jitter 上限。`ConcurrentImportTests` 显式声
明并断言：并发 worker 可能各自命中 `FileNotFoundError` 或
`LegacyImportError(code="ledger_denied")`（accepted transient race
tokens），但至少一个成功；所有成功者返回同一 `crosswalk_key`；串
行 follow-up 调用回到同一 key。**未修改 RT-015 任何字节。**

### 3.2 三类哈希严格区分（现场核对）

对同一份合成 raw：

```
legacy_source_sha256   = SHA-256(raw_bytes)              (示例: 65 chars 十六进制)
canonical_sha256       = SHA-256(canonical_json_bytes(nfc_normalize(envelope without canonical_sha256)))
object_bytes_sha256    = SHA-256(canonical_json_bytes(envelope with canonical_sha256))
```

三者互不相等。crosswalk / decompose_report / RT-014 publish_receipt
分别持有对应字段，永不允许字节复用；`test_rt016_decomposer.HappyPathTests.test_three_hashes_are_distinct`
断言 `assertNotEqual` 三次。

### 3.3 tenant view fail-closed blocker（RT-015 API 边界的明确记录）

生产路径下：

- RT-016 `ShadowImporter.import_one` 不主动调用
  `AccessLedger.promote_to_active`；
- `TenantViewStore.upsert_overlay` 因要求 `active` grant + 未过期
  lease，本无法在生产路径成立；
- crosswalk 记录：`tenant_view_written=False`,
  `tenant_view_deferred_reason="no_authority_receipt_available"`,
  但 `tenant_view_envelope` 字段完整保存 RT-011
  `validate_tenant_view` 通过的 overlay 内容（不含 body、URL、
  credential，含 lane / reply_id + content_sha256 / node_id +
  type + content_sha256 等 overlay-legal 字段），供未来 authority
  上线后 replay。

RT-016 不修改 RT-015 冻结物；不实现 privileged bypass；不宣称完成
M3 / G3 / VG-A / 生产迁移。真实 authority 通道 conservative_unknown
的现状由 RT-011 / RT-015 契约结论继承。
