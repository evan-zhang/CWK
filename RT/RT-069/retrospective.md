# RT-069 复盘

## 目标达成了吗

达成。2026-09-20 上线，`https://192.168.91.72:8793/tokens` 登录后可自助签发、查看、吊销令牌。

线上端到端实测（用真实 Key）：登录 → 签发 → **用新令牌真的检索到了内容（两条命中）** →
对不属于自己的库仍是 403 → 吊销 → 立刻变 401。

## 做对了什么

- **页面化时把铁律加强了，而不是放松**。命令行签发只需要一把 Key；页面签发要求
  会话与当场提供的 Key 指向同一个人。结果是会话被盗签不出、拿别人的 Key 也签不出，
  连管理员都签不出别人的令牌——比原来的命令行更严。
- **验证做到"真的能用"为止**。不是"接口返回 200"，而是拿签出来的令牌去查真实知识库、
  再吊销后确认立刻失效。这条链上任何一段没接好都会在这一步暴露。
- **顺手补掉一个死角**：`admins` 字段从 RT-061 起就存在却无法写入，代码里的管理员分支
  现实中永远走不到。补了命令行的 admin-add/remove，并刻意不做成页面——
  "谁能管所有库"不该从网页发出去。

## 踩到什么

- 测试里一度用 `d.update(...) or d.__setitem__("version", ...)` 这种手法直接篡改授权表，
  绕过了正常的提交路径。写出来就该意识到：**需要在测试里绕过写入路径，说明缺了一个入口**。
  补上 `set_admin` 之后，测试改回走正常路径。
- 又一次被引号咬到：提交信息里的引号把命令拆碎。这次一开始就用文件传。
