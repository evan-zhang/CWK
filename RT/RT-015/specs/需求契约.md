## 二、schema 契约

`PR/PR-001-multitenant-knowledge-spaces/contracts/rt015/schemas/` 独占：

- `access_grant_record.schema.json` — `cwk.rt015.access_grant_record.v1`：
  `additionalProperties:false` + `unevaluatedProperties:false`；
  必填 `schema/grant_key/tenant_id/source_namespace/report_id/grant/
  record_revision/created_at/updated_at`；`grant_key` 匹配
  `^g_[a-z2-7]{26}$`；`grant` 二次由 RT-011 `validate_access_grant`
  校验；deepForbiddenProperties 覆盖 credential/body/reply/attachment/
  temporary_url/path/mirror_root 等。
- `state_transition_event.schema.json` — `cwk.rt015.state_transition_event.v1`：
  `actor` / `reason` 严格 `\A[\x20-\x7e]+\Z`；`event_id` 匹配
  `^ev_[a-z2-7]{26}$`；`from_status` 允许 `_initial_`；`to_status`
  不允许；deepForbiddenProperties 与上同。
- `revoke_intent.schema.json` — `cwk.rt015.revoke_intent.v1`：
  `prior_status ∈ {discovered, granted, active, revalidation_due}`；
  `txn_id` `^rv_[a-z2-7]{26}$`；`authority_receipt_id` 可为 null。
- `revoke_receipt.schema.json` — `cwk.rt015.revoke_receipt.v1`：
  `tenant_auth_epoch_after >= 2`；`tombstone_sha256 /
  cleanup_outbox_sha256` 均为 64 字符 hex。
- `access_tombstone.schema.json` — `cwk.rt015.access_tombstone.v1`：
  同上禁字段 + `tenant_auth_epoch_at_revoke >= 2`。
- `cleanup_outbox.schema.json` — `cwk.rt015.cleanup_outbox.v1`：
  `consumers` 只能是 `{tenant_view, space_index, cache, review_queue,
  archive_metadata}` 的子集，`minItems=1`，`maxItems=8`。
- `authority_receipt.schema.json` — `cwk.rt015.authority_receipt.v1`：
  `receipt_type ∈ {grant_promote, lease_refresh, revoke_confirm}`；
  `permission_source ∈ {authoritative_permission_api,
  delegated_admin_bootstrap}`；`signature` 64 字符 hex；`signer_id`
  `^[a-z0-9._-]+$`。
- `tenant_view_record.schema.json` — `cwk.rt015.tenant_view_record.v1`：
  `view_key` `^g_[a-z2-7]{26}$`（与 grant_key 同格式，因语义同源）；
  `view` 二次由 RT-011 `validate_tenant_view` 校验；deep-forbidden
  覆盖 body / canonical_body / reply_body / node_body。

## 三、错误 taxonomy

| code | 语义 |
| --- | --- |
| `contract` | schema / 字段 / JCS / 类型违反 |
| `not_initialized` | 底层 registry 子目录尚未创建 |
| `not_found` | 请求的 grant/tenant subdir 不存在 |
| `state` | 非法状态迁移或错误来源状态 |
| `conflict` | CAS 冲突 |
| `authority_rejected` | authority adapter 拒绝（默认 fail-closed 或 fake signer 校验失败） |
| `revocation_in_progress` | 存在 in-flight revoke intent |
| `log_injection` | actor/reason 中检测到控制字符 |
| `denied` | `AccessDenied` 的统一 `code`；`reason` 提供内部诊断，不写入 `__str__` |
| `corrupt` | grant / event / tombstone 文件损坏 |
| `unknown_tenant` | 传入 tenant_id 在 RT-012 tenant registry 中不存在 |
| `internal` | RT-015 自身不变量被打破（如 opaque_id 长度） |

`TenantViewError.code`: `not_initialized`, `not_found`, `denied`,
`corrupt`, `canonical_missing`, `overlay_contract`, `purge_refused`, `io`,
`contract`.

  DocDB / Cloud 派生物。

  RT-024 才做基线测量。
