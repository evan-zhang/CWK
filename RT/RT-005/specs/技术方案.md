# RT-005 技术方案

## 1. 涉及模块

- `scripts/cwk_ai_common.py`：reviewer 安全策略和模型调用。
- `scripts/cwk_cloud_wiki_compile.py`：兜底摘要精编与 manifest 状态。
- `scripts/cwk_nightly_pipeline.py`：精编开关透传。
- `scripts/cwk_wiki_batch_driver.sh`：历史质量债批处理。
- `tests/`、`README.md`、`docs/AI-PILOT.md`、`docs/OPERATIONS.md`。

## 2. 数据结构变化

- 不改变 raw 或 summary 文件格式。
- 继续使用 manifest 的 `compiled_report_ids`、`ai_refined_report_ids`、`fallback_report_ids`、`failure_queue`。
- 新增 `withheld_report_ids`；失败队列记录 `attempts`，最多自动尝试 3 次。

## 3. API / 接口变化

- nightly 新增 `--wiki-refine-fallbacks/--no-wiki-refine-fallbacks`。
- 配置新增 `wiki_refine_fallbacks`、`wiki_max_parallel`、`wiki_repair_model`，并提供对应环境变量。

## 4. 前端页面变化

- 无。

## 5. 后端逻辑变化

- reviewer 改为 host 上无 sandbox 运行，但工具 allowlist 必须为空；脚本预检不满足即拒绝。
- OpenClaw CLI 负责读取 `--message-file`，模型工作进程不需要 `read` 工具。
- nightly 在明确启用时向 compiler 追加 `--refine-fallbacks`。
- 精编失败保留原兜底页；敏感原文不送模型并进入安全留存状态；三次失败后停止自动重试。

## 6. 测试策略

- 更新安全策略单测，覆盖 sandbox off + zero tools 以及任何工具权限拒绝。
- 新增 nightly 参数透传单测。
- 运行 tiny lane smoke、单篇精编、全量单测、Wiki lint、真实查询。

## 7. 风险点

- sandbox 关闭后若误授予工具会扩大宿主机风险；通过配置与代码双重门禁消除。
- 批量模型调用可能慢或限流；采用有界批次、失败队列和可恢复 manifest。
- 精编可能改变 topics/entities；精编后重建聚合页并复跑 lint。
