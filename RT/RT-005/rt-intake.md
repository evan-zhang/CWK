# RT-005：工作协同 Wiki 精编闭环与稳定运行

## 目标

在 RT-004 可信问答已经可用的基础上，消除历史兜底摘要质量债，并让新增 raw、摘要精编、主题/实体重建和状态观测形成稳定闭环。

## 边界

- 不改变 `raw/` 唯一事实源和按业务日期分桶规则。
- 不引入 Docker、向量数据库或新的在线基础设施。
- 模型工作进程不得拥有文件、命令、消息、网络工具权限；输入由调用方作为消息传入，输出仅允许 JSON。
- 不执行工作协同回复、审批、转办、标已读等写操作。
- 本 RT 不建设独立 Web UI 或图数据库。

## 验收

1. `cwk-ai-reviewer` 可在 Docker daemon 不可用时完成无工具模型调用。
2. Agent 配置及代码预检共同保证 sandbox 关闭时工具集合为空。
3. 单篇兜底摘要能够经模型精编，并从 `fallback_report_ids` 移入 `ai_refined_report_ids`。
4. nightly 可配置每轮有界精编，且失败不阻断规则链路。
5. Wiki 状态能准确报告 raw、summary、AI 精编、兜底、失败队列数量。
6. 全量测试、lint、真实查询和精编 smoke 均通过。
