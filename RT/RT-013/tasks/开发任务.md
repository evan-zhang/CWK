## T-02 Binding Registry (`cwk_agent_binding.py`)

- opaque hash = HMAC-SHA256(binding_secret, raw_agent_id)；hex 64；
- binding_epoch monotonic +1；每次 mutate 后 `TenantRegistry.bump_auth_epoch`；
- record 位置 `registry/agent-bindings/current/<hash>.json`；receipt 追加式；
- CAS：`cas_write(expected_previous_sha256=record.on_disk_sha256)`；
- lock：`exclusive_lock` on `.<hash>.lock` (agent side) + `.<tenant_id>.lock` (
  tenant side)，字典序取锁；
- rotation：secret pointer + dual-write + tombstone；
- `recover()` 幂等；不解冻已 revoked binding。

## T-03 Credential Broker (`cwk_credential_broker.py`)

- record 位置 `registry/credentials/<tenant_id>.json`；
- backend registry 抽象；`EnvRefBackend` / `FileRefBackend`；
- `lease(agent_context, purpose)` context manager；
  - env whitelist：`{"CWK_INSTANCE_ROOT", "CWORK_APP_KEY"}`；
  - lease id + reference_uri + credential_epoch + tenant_id 写 audit receipt；
  - exit 时 zero-out material buffer；
- purpose × tenant state guard 严格匹配 RT-012 `TENANT_OPERATION_MATRIX`；
- rotation：pointer 单文件写 + 原子切换 + tombstone；
- **拒绝** repo `.env` fallback；`CredentialBackendError` 直接 raise；
- `recover()` 幂等。

## T-04 AgentContext (`cwk_agent_context.py`)

- `TRUSTED_AGENT_SOURCES = frozenset({"gateway_authenticated_context", "admin_cli"})`；
- `from_trusted(*, raw_agent_id, source, purpose, layout)` 只接受白名单 source；
- 不提供 `from_untrusted / from_request_body / from_env / from_argv`；
- `snapshot()` 返回 dataclass；`redact()` 用于日志（只 hash 前 8）；
- `__repr__` / `__str__` 不泄漏 raw_agent_id / material。
