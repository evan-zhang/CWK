## 冻结的 RT-013 契约清单

`PR/PR-001-multitenant-knowledge-spaces/contracts/rt013/schemas/`：

- `agent_binding.schema.json` — `cwk.rt013.agent_binding.v1`：
  `agent_id_hash` = 64 位 hex；`tenant_id` = opaque；
  `binding_epoch/binding_secret_epoch >= 1`；`status ∈ {active, suspended, revoked}`；
  `bound_at/updated_at` 强 RFC 3339；`revoked_at` 允许 null；`provisioning` 含
  `last_receipt_id/last_receipt_sha256`；`additionalProperties:false +
  unevaluatedProperties:false`；顶层 forbidden set 包含
  `raw_agent_id/app_key/credential_ref/mirror_root/absolute_path`。
- `credential_ref.schema.json` — `cwk.rt013.credential_ref.v1`：
  `reference_uri` = `secret://[a-z0-9._-]{1,128}$`；`backend ∈ {env_ref, file_ref}`；
  `status ∈ {active, disabled, revoked, rotating}`；`credential_epoch >= 1`；
  `dual_write` 时需含 `secondary_reference_uri` + `secondary_backend`；
  永不允许 `material / secret / app_key / value / plaintext / token / cookie`。
- `binding_secret_pointer.schema.json` — `cwk.rt013.binding_secret_pointer.v1`：
  `rotation_state ∈ {stable, dual_write, finalizing}`；`current_epoch >= 1`；
  `secondary_epoch/previous_epoch` 可 null。
- `binding_receipt.schema.json` — `cwk.rt013.binding_receipt.v1`：
  `receipt_id ^rbnd_[a-z0-9]{26}$`；`action ∈ {bind, rebind_out, rebind_in, revoke, suspend, reactivate, secret_rotation_begin, secret_rotation_finalize}`；
  `receipt_sha256` 完整比对；不含 raw_agent_id / material。
- `credential_broker_lease.schema.json` — `cwk.rt013.credential_broker_lease.v1`：
  `lease_id ^lease_[a-z0-9]{26}$`；仅含 `reference_uri` + `credential_epoch`；
  绝不含 material。

## 与 RT-011 / RT-012 契约的关系

- RT-013 **只读** RT-011：`TENANT_ID_REGEX`、`SPACE_ID_REGEX`、`SHA256_HEX_REGEX`、
  `IJSON_MAX_SAFE_INT`、`strict_json_loads/strict_json_load_path`、
  `canonical_json_bytes/canonical_sha256`、`ContractError`、`_validate_schema`（
  仅用于 RT-013 schemas 的 Draft-2020-12 校验）。
- RT-013 **只读/只调用** RT-012：`cwk_atomic_file` 全部原子 / lock / CAS API；
  `cwk_instance` 全部 dirfd 抽象；`cwk_tenant_registry` 的
  `TenantRegistry.get / bump_auth_epoch / TENANT_OPERATION_MATRIX / TENANT_STATES`。
- **唯一变更 to RT-012 files**：`cwk_tenant_cli.py` 的 `FROZEN_PROVIDER_SLOTS`
  追加一行 `"cwk_tenant_cmd_binding"`（RT-012 dispatcher 已在源代码注释里预留
  该 slot；RT-012 独立验收 §8 显式允许 RT-013 通过“加入 tuple”的方式注册）。
  dispatcher 的加载、ABI、CWD/PYTHONPATH 忽略、`_safe_env_snapshot` 等逻辑一
  行未动。
