## 字节 / ID 契约

### `catalog_key`

```python
_CATALOG_KEY_DOMAIN = b"cwk-rt014-report-key-v1\x00"

def _catalog_key(report_key: str) -> str:
    digest = hashlib.sha256(_CATALOG_KEY_DOMAIN + report_key.encode("utf-8")).digest()[:16]
    body = base64.b32encode(digest).decode("ascii").rstrip("=").lower()
    return f"r_{body}"

CATALOG_KEY_REGEX = re.compile(r"\Ar_[a-z2-7]{26}\Z")
```

- 128 位 domain-separated SHA-256 前缀，base32 小写；
- 全 opaque，`report_id`/`namespace` 永不出现在路径；
- 相同 `report_key` 恒定映射；跨进程/宿主机可复现。

### `object shard`

```python
def _object_shard(object_id: str) -> str:
    _validate_object_id(object_id)
    return object_id[2:4]  # 2 char base32 → 32 possible dirs
```

- shard 目录只在 publish 时 lazily `mkdir_at`，`exist_ok=True`。

### catalog head sha256

```python
head_payload = {

```

`cas_write` 的 `expected_previous_sha256` = 上次 head 文件 sha256（`hashlib.sha256(head_bytes_old).hexdigest()`）。

## 校验器

- `_validate_head(head_dict)`：schema `cwk.rt014.catalog_head.v1` + `catalog_key` regex +
  `entry_count == head_revision` + `catalog_jsonl_sha256` hex；
- `_validate_entry(entry_dict)`：schema `cwk.report_version.v1` + report_key 组合合法 +
  object_id 组合合法 + canonical_sha256 hex；
- 通过 RT-011 的 `_validate_schema` engine 复用。

## 发布顺序（严格不可重排）

```python
def publish(self, envelope: dict) -> PublishReceipt:
    # 1. Strict validate + recompute SHA (RT-011)
    C.validate_canonical_envelope(envelope)                       # deep-forbidden + hash recompute
    canonical_sha256 = envelope["canonical_sha256"]
    report_key = C.compose_report_key(envelope["source_namespace"], envelope["report_id"])
    catalog_key = _catalog_key(report_key)
    body_bytes = C.canonical_json_bytes(envelope)                  # NFC+JCS+UTF-8, 与 SHA 输入相同
    # 复核：SHA(body_bytes) == canonical_sha256 除 `canonical_sha256` 字段外，
    # 但对象要保存完整 payload（含 canonical_sha256）。为兼容 reader:
    # canonical envelope 内含 canonical_sha256 字段；对象字节 = canonical_json_bytes(envelope)。
    # reader 读回时，验证 sha256(body_bytes)==sha256_of_full_payload_from_head 且
    # RT-011 canonical handler 再次做 recompute（去 sha 字段 → 序列化 → sha）。

    with self._shared_fd() as sfd, self._locks_fd(sfd) as lfd:
        with A.exclusive_lock(lfd, f"{catalog_key}.lock", blocking=True):
            # 2. Open per-report dir (lazy mkdir)
            with self._report_dir_fd(sfd, catalog_key, create=True) as rfd:
                head_dict, head_bytes_old = self._read_head(rfd)
                entries = self._read_entries(rfd, expected_count=head_dict["entry_count"] if head_dict else 0)
                # 3. Idempotency check
                for e in entries:
                    if e["canonical_sha256"] == canonical_sha256:
                        # cross-check: object still there and hashes match
                        self._reverify_object_on_disk(sfd, e["object_id"], canonical_sha256)
                        return PublishReceipt(
                            report_key=report_key,
                            canonical_sha256=canonical_sha256,
                            object_id=e["object_id"],
                            catalog_key=catalog_key,
                            is_new_version=False,
                            is_new_report=False,
                            catalog_revision=head_dict["entry_count"],
                            catalog_head_sha256=_sha256_bytes(head_bytes_old),
                        )
                # 4. Allocate opaque object id, publish object atomically first
                object_id = C.new_object_id()
                shard = _object_shard(object_id)
                with self._objects_fd(sfd) as ofd, self._shard_fd(ofd, shard, create=True) as shard_fd:
                    A.write_atomic(shard_fd, f"{object_id}.json", body_bytes, exclusive=True)
                # 5. Compose new entry
                entry = {
                    "schema": "cwk.report_version.v1",
                    "report_key": report_key,
                    "canonical_sha256": canonical_sha256,
                    "object_id": object_id,
                    "first_seen_at": _utc_iso(),
                    "source_updated_at": envelope["source_updated_at"],
                    "normalizer_version": envelope["normalizer_version"],
                }
                _validate_entry(entry)
                entries.append(entry)
                jsonl_bytes = b"".join(C.canonical_json_bytes(e) + b"\n" for e in entries)
                # 6. CAS-write catalog.jsonl (full rewrite) inside lock
                #    expected_previous_sha256 = hash of old jsonl (or None if first)
                self._cas_write_jsonl(rfd, jsonl_bytes, head_dict)
                # 7. CAS-write catalog.head
                new_head = _make_head(catalog_key, report_key, entries, jsonl_bytes,
                                      created_at=head_dict["created_at"] if head_dict else entry["first_seen_at"])
                head_bytes_new = C.canonical_json_bytes(new_head)
                A.cas_write(rfd, "catalog.head", head_bytes_new,
                            expected_previous_sha256=(hashlib.sha256(head_bytes_old).hexdigest() if head_bytes_old else None))
                # 8. fsync report dir (write_atomic already does this)
                return PublishReceipt(
                    report_key=report_key,
                    canonical_sha256=canonical_sha256,
                    object_id=object_id,
                    catalog_key=catalog_key,
                    is_new_version=True,
                    is_new_report=(head_dict is None),
                    catalog_revision=len(entries),
                    catalog_head_sha256=hashlib.sha256(head_bytes_new).hexdigest(),
                )
```

关键不变式：
- `exclusive_lock` 序列化同 `report_key` 的写者；
- 对象文件先写入并 `fsync`，之后才允许更新 catalog；
- 若 catalog 写入失败（RevisionConflict / IO 错），已发布对象成为孤儿；`recover()` 报告
  为 `catalog_issues[].code = "orphan_object"`，绝不删除。

## 读取顺序（严格）

```python
def read_version(self, report_key: str, canonical_sha256: str) -> dict:
    _validate_report_key(report_key)
    _validate_sha256(canonical_sha256)
    catalog_key = _catalog_key(report_key)
    with self._shared_fd() as sfd:
        with self._report_dir_fd(sfd, catalog_key, create=False) as rfd:
            head_dict, head_bytes_old = self._read_head(rfd)
            if head_dict is None:
                raise SharedEvidenceError("catalog head missing", code="not_found")
            entries = self._read_entries(rfd, expected_count=head_dict["entry_count"])
            # head↔jsonl consistency
            if head_dict["catalog_jsonl_sha256"] != _sha256_bytes(self._raw_jsonl_bytes):
                raise SharedEvidenceError("catalog head/jsonl SHA mismatch", code="corrupt_catalog")
            # 找到目标 entry
            matches = [e for e in entries if e["canonical_sha256"] == canonical_sha256]
            if not matches:
                raise SharedEvidenceError("version not in catalog", code="not_found")
            entry = matches[0]
            if entry["report_key"] != report_key:
                raise SharedEvidenceError("catalog entry report_key mismatch", code="report_key_mismatch")
            # 读对象
            with self._objects_fd(sfd) as ofd, self._shard_fd(ofd, _object_shard(entry["object_id"]),
                                                              create=False) as shard_fd:
                try:
                    raw = A.read_file(shard_fd, f"{entry['object_id']}.json")
                except FileNotFoundError:
                    raise SharedEvidenceError("catalog references missing object", code="orphan_object")
                except A.ContainmentError as exc:
                    raise SharedEvidenceError("object failed containment", code="contract") from exc
            if hashlib.sha256(raw).hexdigest() != canonical_sha256:
                raise SharedEvidenceError("object bytes sha mismatch", code="sha_mismatch")
            try:
                payload = C.strict_json_loads(raw.decode("utf-8"))
            except (UnicodeDecodeError, C.ContractError) as exc:
                raise SharedEvidenceError("object body is not strict JSON", code="contract") from exc
            try:
                C.validate_canonical_envelope(payload)
            except C.ContractError as exc:
                raise SharedEvidenceError("object body fails RT-011 schema", code="contract") from exc
            if C.canonical_json_bytes(payload) != raw:
                raise SharedEvidenceError("object body is not canonical JCS", code="canonical_drift")
            if payload["canonical_sha256"] != canonical_sha256:
                raise SharedEvidenceError("object body sha field mismatch", code="sha_mismatch")
            if C.compose_report_key(payload["source_namespace"], payload["report_id"]) != report_key:
                raise SharedEvidenceError("object body report_key mismatch", code="report_key_mismatch")
            return payload
```

## `recover()`

- 打开 shared/staging → `A.recover_orphans(fd)` 得到 removed list；
- 打开 shared/report-versions/，遍历 catalog_key 子目录：
  - 每个目录 `A.recover_orphans(rfd)`（清理 `.cwk-tmp-*`）；
  - `_read_head` / `_read_entries` 严格校验；schema 违规 → `catalog_issues.append({code:"corrupt_catalog", catalog_key})`；
  - 每个 entry 打开对象文件；缺失 → `missing_object`；SHA 不符 → `sha_mismatch`；
- 打开 shared/objects/**：不主动清理孤儿（策略：保留供审计与 GC）；只在 catalog 侧发现问题时报告；
- 返回 `RecoveryReport` dict，校验 `cwk.rt014.recovery_report.v1`。

## 错误消息 opacity

- `SharedEvidenceError` 只格式化 `code` + 短固定描述 + 至多 `catalog_key` / `object_id` 两个
  opaque token；
- 不 include `CWK_INSTANCE_ROOT` 绝对路径；不 include 报告正文；不 include `report_id`；
- test `str(exc)` 断言不含 `/`（在错误消息本身；opaque IDs 显然不含 `/`）以及不含 `report_id` 明文。
