# RT-006 技术方案

## 1. 涉及模块

- `cwk_cloud_wiki_compile.py` / 新增 manifest reconcile 工具：安全维护 source 与质量状态。
- `cwk_sync_mirror_to_docdb.py`：raw deny-list、显式允许开关、对象映射输出。
- 新增 search-index builder：持久化词法倒排索引和 index meta。
- `cwk_wiki_query.py`：读取持久索引，支持 local/cloud/shadow provider。
- 新增 cloud coverage audit / restore 工具。
- `cwk_nightly_pipeline.py`：索引构建、云端同步、严格审计和读己之写提交顺序。
- tests、DESIGN、USER_GUIDE、SECURITY、OPERATIONS。

## 2. 数据结构变化

### `wiki/_system/manifest.json`

- 安全更新 `source_count`、`source_hashes`、`source_lanes`、`source_months`。
- 保留 `compiled_report_ids`、`ai_refined_report_ids`、`fallback_report_ids`、`withheld_report_ids`、`failure_queue`。
- 新增 `index_version`、`search_index_sha256`、`cloud_object_manifest_sha256`。

### `wiki/_system/search-index.json`

- 文档元数据：report_id/title/writer/date/lane/summary_quality/raw_sha256/cloud ids。
- 词法索引：doc lengths、term frequencies、document frequencies/IDF 或等价 postings。
- 内容哈希和 schema version。

### `wiki/_system/cloud-objects.json`

- relative_path、file_id、content_sha256、version/update 时间。
- raw 与 Wiki 均可对账；不保存鉴权值。

### summary frontmatter

- 保留本地 `source` 相对路径用于兼容。
- 新增 `source_report_id`、`source_sha256`、可选 `source_cloud_file_id`。

## 3. API / 接口变化

- 同步器新增 `--allow-raw`，默认拒绝 raw。
- 查询器新增 `--mode local|cloud|shadow`、`--cache-dir`、`--cloud-object-manifest`。
- nightly 新增 search-index、cloud audit 和 strict cloud gate 开关。
- restore 工具接受隔离目标目录和 cloud object manifest。

## 4. 前端页面变化

- 无独立前端；查询结果增加云端 fileId/预览入口和 provider 状态。

## 5. 后端逻辑变化

- manifest 使用 merge/reconcile，不再由 bootstrap 整体覆盖质量状态。
- search index 作为可重建派生物；查询优先读 index，缺失或版本不兼容时回退现有全扫。
- cloud provider 通过 DocDB 批量读取 Top-K raw，校验 sha256 后复用原引文验证逻辑。
- 写入顺序先发布版本化 index 分片和 metadata，最后发布 `cloud-objects.json` 形成伪事务提交点；旧目录在新目录提交前始终可读。
- local/cloud 双读结果可在 shadow 模式比对并记录一致率。

## 6. 测试策略

- 单元：manifest merge、deny-list、索引确定性、缓存失效、cloud provider、restore。
- 集成：本地查询回归、DocDB dry-run、云端对象对账、断网/限流失败。
- 性能：旧全扫 vs 持久索引，记录 P50/P95。
- 恢复：两个独立空目录执行恢复并验证哈希、lint、smoke。
- 安全：raw 未显式授权不得上传，secret 不进入日志。

## 7. 风险点

- raw 上云扩大隐私边界：限制个人空间、无分享、版本化上传并保留审计。
- DocDB API 不提供正文搜索：search index 必须作为云端对象由 Agent 下载后本地召回。
- 1,450 个对象串行操作耗时长：使用有界并发和可恢复 manifest。
- 云端唯一主库会引入网络/鉴权 SPOF：本 RT 不删除本地副本，并完成双读与恢复演练后再决策。
