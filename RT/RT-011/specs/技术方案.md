## 字节契约

### `ReportKey`

```python
compose_report_key(source_namespace, report_id) -> "cwork:207xxxx"
```

- `source_namespace` 满足 `^[a-z][a-z0-9_]*$`；
- `report_id` 满足 `^[^\s]{1,256}$`；
- 拼接以 `:` 分隔，长度 ≤ 64+1+256；
- 同一 `report_id` 在不同 namespace 下产生**不同** `report_key`，永不合并。

### `object_id`

```python
new_object_id() -> "o_" + base32(secrets.token_bytes(16)).lower().rstrip("=")
```

- 128 位随机；
- base32 alphabet `[a-z2-7]`；
- 全小写 26 字符，无 padding；
- 正则 `^o_[a-z2-7]{26}$`；
- 不使用 SHA-256 作为对外 ID，也不提供 hash existence API。

### Canonical JSON（NFC → JCS → UTF-8）

```python
canonical_json_bytes(value) -> bytes
canonical_sha256(value)     -> hex(64)
```

流程：
1. 递归 `unicodedata.normalize("NFC", ...)`；
2. RFC 8785 JCS：
   - 对象键按 UTF-16-BE 字节排序（与代码点排序一致但对 SMP 更稳）；
   - 字符串仅转义 `"` `\` 与控制字符（`\bfnrt` 或 `\uXXXX`）；
   - 数字用 ECMA-262 表示（整数直出，浮点使用 `repr`，禁 NaN/Infinity）；
   - 布尔用 `true/false`；`null` 用 `null`；无空白；
3. UTF-8 编码。

### `profile_sha256`

```python
sha256(
    b"cwk-profile-v1" + b"\x00"
    + canonical_json_bytes(nfc_normalized_proposal) + b"\x00"
    + sample_manifest_sha256.encode("ascii") + b"\x00"
    + prompt_template_sha256.encode("ascii") + b"\x00"
    + model_id.encode("utf-8")
)
```

- 每个组件用 `0x00` 分隔，禁止无分隔符拼接；
- `sample_manifest_sha256` / `prompt_template_sha256` 必须匹配 `^[0-9a-f]{64}$`，否则 `ContractError`；
- `model_id` 非空 UTF-8；
- 缺任一输入 → `ContractError`。

## 校验器

- 十三个 `validate_*` 函数按 payload `schema` 字段派发；`validate(payload)` 统一入口。
- 每个函数都强制：
  - 正则 / enum / 类型；
  - `forbiddenProperties`（Canonical / QueryRequest / KnowledgeProfile）；
  - 状态机转移合法性（`validate_access_grant_transition` / `validate_knowledge_profile_transition`）；
  - 特殊规则：`profile_pointer_rollback` 要求 `from_version != to_version` 且 `auth_epoch_after > auth_epoch_before`；
    `verified_shared_extensions` 禁止 URL / 身份路径且 `compared_sample_size ≥ 50`；
    `sample_manifest` holdout / samples 不重叠；
    `capability_probe` 禁止 `sandbox_transport_loopback_http_self_reported` 升级；
    Canonical `canonical_sha256` 必须与去除该字段后再规范化的 SHA 一致。

## 能力探针骨架

`scripts/cwk_pr001_probes.py`：

- 九个 probe_id；
- `EvidenceBundle.is_authoritative` 要求：
  - `probe_id ∉ POLICY_FORBIDDEN_UPGRADE`；
  - `kind == "controlled_environment_receipt"`；
  - `refs` 非空且不含 `fixture://` 前缀；
  - `verified_shared_extensions_dual_user_sample` 还要求 `unique_report_key_pairs ≥ 50`；
- `aggregate` 返回 `all_verified` 布尔与 `policy_forbidden_probe_ids` 列表。

## 双用户比较器

`scripts/cwk_pr001_view_compare.py`：

- `TenantEnvelopeSet` 构造时立即：
  - 校验 `tenant_id` 正则；
  - 每个 envelope 走 `validate_tenant_view`；
  - 拒绝键：`app_key / appKey / credential_ref / credentials / cookie / session_token / authorization / authorization_header`；
- `compare(a, b)`：
  - 计算 `sample_sizes`、`only_in_*`、`canonical_sha256_mismatches`；
  - 逐字段一致率（`_iter_leaf_paths`）；
  - `reply/node/attachment` 差异计数；
  - 建议：
    - `common ≥ 50` 且 `match_rate ≥ threshold` → `candidate_verified_shared`；
    - URL / 身份字段无条件 `keep_in_tenant_overlay`。

## CLI

`scripts/cwk_pr001_cli.py`：

- argparse 子命令：`validate / canonicalize / sha256 / profile-hash / compare-user-views / probe run|aggregate / conformance`。
- 退出码固定为 0/2/3/4/5；异常路径打印 `contract-error: <path>: <msg>` 或 `error: <safe-message>`；从不打印 traceback；从不回显绝对路径（`_safe_path` 只保留尾部两级）。
