# RT-011 需求契约

## 用户 / 系统动作与系统响应

| 动作 / 触发 | 系统响应 | 成功标准 | 失败处理 |
| --- | --- | --- | --- |
| 下游 RT 引用 `ReportKey` | 统一使用 `source_namespace + ":" + report_id`；跨 namespace 相同 `report_id` 不合并 | `compose_report_key` / `parse_report_key` 通过；`test_report_key_namespace_isolation` 绿 | 缺 namespace 或非法字符：`ContractError`，退出码 2 |
| 下游 RT 生成 `object_id` | 返回 `"o_" + base32(random 128 bit)` 全小写，无 padding | 26 个字符 `[a-z2-7]`；`OBJECT_ID_REGEX.match(oid)` | 非 128 bit / 非 base32 / 非小写：`ContractError` |
| 任意组件把 CanonicalEnvelope 与 TenantView 混写 | Canonical Schema 拒绝 tenant/lane/read/todo/reply/node/attachment/临时 URL 等 30+ forbidden field | 正例通过，负例 `ContractError` | 不允许合并；升级需 `verified_shared_extensions_vN` 且临时 URL 永不升级 |
| 组件序列化 payload 计算 SHA | 先 NFC 规范化字符串，再 RFC 8785 JCS，最后 UTF-8 | NFC vs NFD 输入得到相同字节；数字/字符串/布尔按 RFC 8785 | NaN/Infinity 拒绝；bool 不允许被当数字 |
| Profile 组件生成 `profile_sha256` | 按 domain-separated 公式：`sha256(b"cwk-profile-v1"+0x00+jcs_utf8(nfc_normalized_proposal)+0x00+sample_manifest_sha256_ascii+0x00+prompt_template_sha256_ascii+0x00+model_id_utf8)` | 单元测试与公式手工重算一致 | 缺 sample/prompt/model：`ContractError` |
| Router 输出 `RouteDecision` | `space_ids[]` 元素必须匹配 `^sp_[a-z0-9]{10,32}$` | slug/重复/未知 disposition 全部被拒 | 负例返回 `ContractError` |
| 沙箱 Skill 生成 `QueryRequest` | 无 `tenant_id/agent_id/credential_ref/path/profile_sha256/auth_epoch`；`space_selector[]` 元素必须 opaque | 负例（slug、身份注入）被拒 | 返回 `ContractError`，CLI 退出码 2 |
| Profile 版本发生回滚 | 状态机不允许 `rolled_back`；回滚通过 `profile_pointer_rollback` 事件表达；`auth_epoch_after > before`；`from_version != to_version` | 事件 schema 校验通过 | 状态出现 `rolled_back` 或 auth_epoch 不递增：拒绝 |
| Access Grant 状态推进 | 严格按七状态 DAG：discovered→granted→active→revalidation_due→active/revoked；revoked→purge_pending→purged | 允许边通过；`purged→active` 之类拒绝 | 只有 `active` 允许作为查询候选来源 |
| Access Observation 入账 | `initial_status` 只允许 `discovered/granted` | 迁移 / collector 无法直接写 `active` | 违反则 `ContractError` |
| 用户运行 `cwk contract compare-user-views` | 输入两组脱敏 envelopes；输出共同可见、字段一致率、reply/node/attachment/临时 URL 差异、shared/overlay 建议 | 共同样本 <50 或 URL/身份字段禁止升级为 shared | 输入含 `app_key/credential_ref/cookie/session_token/authorization` 立即 `ContractError` |
| 用户运行 `cwk pr001 probe run/aggregate` | 默认全部 `conservative_unknown`；只有 `controlled_environment_receipt` 且 `refs` 非 `fixture://` 才可能 verified；aggregate 返回 `all_verified=false` 时 CLI 退出码 3 | 默认矩阵所有 probe conservative，`policy_forbidden_probe_ids` 包含 loopback HTTP | fixture/mock 证据永不升级；forbidden probe 永不升级 |
| 运维检查安全默认 | `cwk pr001 conformance --file candidate.json` 与 `security_defaults.json` 深度比对 | 一致返回 0；不一致返回 2 并列差异 | 差异内容必须机器可读 |
| CLI 收到未知子命令 / 缺参 / 坏 JSON / 找不到文件 | 稳定退出码 2 / 4 / 5，无 traceback，无绝对路径回显 | `test_pr001_cli.py` 全部通过 | 内部异常路径也不打印 traceback |

## 冻结的 v1 契约清单（schema 文件位置）

`PR/PR-001-multitenant-knowledge-spaces/contracts/schemas/` 下：

- `report_key.schema.json` — `ReportKey v1`
- `canonical_report.schema.json` — `CanonicalEnvelope v1`（含 forbiddenProperties 30+）
- `tenant_view.schema.json` — `TenantViewEnvelope v1`
- `access_observation.schema.json` — `AccessObservation v1`（initial_status ∈ {discovered, granted}）
- `access_grant.schema.json` — `AccessGrant v1`（七状态 + allowedTransitions）
- `knowledge_profile.schema.json` — `KnowledgeProfile v1`（六状态 + allowedTransitions + forbiddenProperties）
- `profile_pointer_rollback.schema.json` — 回滚事件
- `route_decision.schema.json` — `space_ids[]` opaque
- `query_request.schema.json` — `space_selector[]` opaque + forbiddenProperties
- `sample_manifest.schema.json` — 采样 manifest（100–200，holdout ≥1 且不重叠）
- `verified_shared_extensions.schema.json` — 升级清单（compared_sample_size ≥50，URL/身份路径永禁）
- `capability_probe.schema.json` — probe 结果（enum `verified | conservative_unknown`）
- `security_defaults.schema.json` — 机器可读安全默认

`PR/PR-001-multitenant-knowledge-spaces/contracts/`：

- `security_defaults.json` — 冻结值（不含虚构 SLA 数字）
- `verified_shared_extensions_v1.json` — bootstrap 空 manifest
- `adr/ADR-0001-transport-and-identity.md` — 传输 / 身份 ADR

## 公开 CLI

命令前缀：`python3.11 scripts/cwk_pr001_cli.py <sub>`

- `validate --file <path> [--schema <schema_id>]`
- `canonicalize --file <path>` — stdout 为 NFC+JCS+UTF-8 字节
- `sha256 --file <path>` — 打印规范 SHA-256
- `profile-hash --proposal <p> --sample-manifest <s> --prompt-template-sha256 <hex> --model-id <str>`
- `compare-user-views --tenant-a <A.json> --tenant-b <B.json> [--threshold 0.99]`
- `probe run [--evidence <e.json>]` — 输出概率 JSON 数组
- `probe aggregate <files...>` — all_verified→exit 0；否则 exit 3
- `conformance --file <candidate.json>` — 与 `security_defaults.json` 深比对

退出码：
- 0：成功
- 2：契约 / schema 错误
- 3：probe aggregate 报告 `all_verified=false`
- 4：使用错误
- 5：IO 错误
- 任何情况下不打印 Python traceback，且不回显 host 绝对路径。

  scheduler、router、projector、query broker；
- 不联网、不访问 CWork API、不读 `.env`、不写 `runs/` `state/` `cache/`；
- 不改 `cron`、`Cloud/DocDB`、`nightly`、生产镜像；
- 不改 `.serena/`、`.spec-workflow/`；
- 不在 RT-011 内 “自我验收”；独立验收由 `agent-rt011-verify` 完成，本 RT 不出具 PASS。

## 验收标准（自测面）

`agent-rt011-verify` 会以黑盒方式检查以下条件。本实现负责让它们全部通过：

1. **CLI 稳定退出码 / 无 traceback / 无绝对路径**：`tests/test_pr001_cli.py`。
2. **九类核心 schema 正反例**：`tests/test_pr001_contracts.py`。
3. **ReportKey namespace 隔离 & object_id 全 opaque**：contracts 测试 + 恶意 fixture。
4. **Canonical 与 tenant overlay 严格分离**：`test_canonical_envelope_rejects_forbidden_fields`。
5. **Grant 七状态仅 active 可读 / Profile 回滚仅 pointer event / 无 rolled_back**：contracts 测试。
6. **`RouteDecision.space_ids` 与 `QueryRequest.space_selector` 只接受 opaque**：contracts 测试 + 恶意 fixture。
7. **sample/holdout 不重叠 & profile SHA 公式精确对齐**：contracts 测试。
8. **`verified_shared_extensions` 至少 50 个唯一共同样本 & 临时 URL 永不升级**：contracts 测试。
9. **九类 probe 只能 verified|conservative_unknown / 5 类核心探针骨架 / fixture 不升级 / aggregate all_verified=false**：`tests/test_pr001_probes.py` + `tests/test_pr001_cli.py`。
10. **ADR 安全默认有机器可执行 conformance**：`cwk pr001 conformance` + `test_conformance_*`。
11. **双租户恶意 fixture manifest / SHA / canary**：`tests/test_pr001_malicious_fixtures.py`。
12. **标准 RT-011 文档包 & 范围 / 回滚 / unknown 显示**：本 RT `rt-intake.md` / 需求契约 / 技术方案 / 开发任务 / 实现记录 / 交付验证报告。
