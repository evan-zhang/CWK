## 关键权衡

- **自研 JCS**：为避免引入第三方依赖并保持 Python 3.11+ 标准库范围内运行，
  在库内实现 RFC 8785 JCS 的对象键 UTF-16-BE 排序、字符串仅转义 `"` / `\` / 控制字符、
  数字按 ECMA-262 输出。测试 `test_jcs_sort_keys_and_no_whitespace` 冻结了输出字节。
- **domain-separated `profile_sha256`**：在 formula 中使用 `\x00` 分隔并把
  `sample_manifest_sha256` / `prompt_template_sha256` 作为 ASCII、`model_id` 作为 UTF-8 提交，
  测试 `test_profile_sha256_formula` 手工重算一次以锚定字节公式；
  `test_profile_sha256_is_domain_separated` 通过 sample/prompt 换位得到不同 hash 证明域分离。
- **fixture 不能升级 probe**：通过 kind 白名单 + `fixture://` 前缀 double-check，
  防止 RT-011 自身或后续 RT 用 fixture “完成”外部事实。
- **CLI 不打印 traceback**：`main` 顶层捕获 `Exception` 并输出 `error: internal failure (<class>)`；
  但不吞掉 `SystemExit`（argparse 自身仍走 exit 2）。
