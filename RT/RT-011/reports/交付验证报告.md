## 3. 与 r1 阻塞的一一对应

| r1 finding | 修复入口 | 首失后过回归测试 |
|---|---|---|
| Validator 只做浅层禁止词扫描 | `_validate_schema` + `additionalProperties:false` 逐层 | `test_canonical_rejects_nested_tenant_id_inside_author` |
| JSON parser 未拒重复键 / NFC 冲突 | `_forbid_duplicate_pairs` + `nfc_normalize` 碰撞检测 | `test_strict_json_loads_rejects_duplicate_keys` / `test_nfc_key_collision_raises` |
| Probe 仅需 kind+任意 ref 就升级 verified | ReceiptEnvelope + `TRUSTED_PROBE_SIGNERS` + 签名/target/environment/时间窗 检查 | `test_receipt_*_rejected` 系列 |
| aggregate 在集合不完整时可能 all_verified=true | `aggregate.complete + missing_probe_ids` 双重门禁 | `test_aggregate_incomplete_forces_all_verified_false` |
| CLI 回显绝对路径 / notes / refs | `_safe_path` + probe schema 无 notes/refs + `_redact_probe` | `test_validate_missing_file_exits_io_5_no_abs_path` |
| Comparator 建议 tenant overlay / 1-of-50 / threshold=0 | `CANDIDATE_CANONICAL_FIELDS` 白名单 + 覆盖门槛 + threshold 硬地板 | `test_only_candidate_paths_are_suggested`、`test_49_common_never_upgrades`、`test_threshold_*_rejected` |
| Duplicate/conflicting entries silently accepted | 加载期 duplicate report_key 报错；canonical_sha 不一致 block upgrade | `ComparatorInputSecurityTests.test_duplicate_report_key_within_tenant_rejected`；`test_canonical_sha_mismatch_blocks_upgrade` |
| JCS 未对齐 RFC 8785 / I-JSON | ECMA-262 `_js_number_string` + I-JSON 边界 | `JcsNumberVectorsTests.*` |
| `security_defaults` 未拒 loopback/break_glass alt | `_security_defaults_handler` deep dangerous scan | `test_conformance_detects_*` + `SecurityDefaultsTests.*` |
| `sample_manifest` 缺唯一性/covariance 校验 | `_sample_manifest_handler` 五项聚合校验 | 5 项 `malicious_sample_manifest_*` |
| `verified_shared_extensions` 缺 SHA 重算/≥50 unique | `_verified_shared_handler` 重算 + 字段级 50 unique | `test_verified_shared_extensions_recompute_manifest_sha` 等 |
| `KnowledgeProfile` 保留旧 hash 通过 | `_profile_handler` 重算 `profile_sha256` | `test_knowledge_profile_positive_and_recompute` + `malicious_profile_sha_recompute_drift.json` |
| ID/SHA regex 接受尾换行；datetime 未强制时区 | `\A..\Z` 锚 + `_check_datetime` 强制 TZ | `TrailingNewlineTests.*` |
| `object_id` 未验证 canonical Base32 | `validate_object_id` 增 base32 alphabet + tail bit 检查 | `test_reject_invalid_canonical_base32_tail` |
| Fixture manifest 与 malicious/canary 不一致 | 真实 `__canary__.json` + 独立 SHA oracle + 全覆盖断言 | `FixtureManifestTests.*` |
