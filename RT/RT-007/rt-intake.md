# RT-007：工作协同动态事项时间线与决策链可信同步

## 目标

把汇报后的评论、回复、审批意见及节点状态纳入 CWK 的可审计证据链，使项目问答可区分原始汇报、后续意见与当前状态。

## 边界

- 全程只读 CWork；禁止回复、审批、转办、完成或标已读。
- 原始事件不可变、可哈希核验；模型不得改写事实。
- 不改变现有 raw 按业务日期的主路径和既有 query 兼容性。
- Scheduler 只提供模板，未核验现有配置和通过演练前不自动启用高频轮询。

## 验收

1. `replyList`、`nodeList` 生成可定位到原汇报的独立事件。
2. 同一响应重复采集幂等；回复/审批状态变化形成新增事件并保留旧快照。
3. 事件、快照和主 raw 都进入变更清单，以便 Cloud-First 同步。
4. 审计能校验最新 raw 中的回复/节点事件均已纳入时间线。
5. 现有单测与新增时间线测试全部通过。
