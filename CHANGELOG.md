# Changelog

## v0.1.0-internal

- Initial internal production package for CWK mirror workflow.
- Includes read-only CWork collection pipeline.
- Generates daily Markdown and standalone HTML digests.
- Supports incremental-link preview against an optional history baseline.
- Supports optional DocDB knowledge-base mirror sync.
- Adds private config template, migration docs, operations docs, privacy and security notes.
- Adds Makefile smoke test, install script, GitHub Actions CI, and sanitized smoke fixture.
